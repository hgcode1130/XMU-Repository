# 大二下 学习资料

本目录下整理了大二下学年的课程资料，该学期由高难度的专业核心课（计组、操作系统基础、算法）组成，是专业能力提升最快的阶段。

## 📁 课程详细列表

### 🌐 系统与架构

- **CNI (计算机网络)**
  - **实验 (CHI-Exp)**：包含完整的网络协议分析与模拟实验报告。
  - **资源**：课件、平时作业 (Homework)、课堂笔记及期末复习全套资料。
- **计算机组成原理**
  - **核心实验**：涵盖 CPU 设计、指令集实现等关键实验。
  - **资料包**：期中/期末试卷、课堂笔记、平时作业及复习范围。
- **数据库系统**
  - **实践**：包含 SQL 语言实验、平时作业练习。
  - **考试**：收录期中、期末历年试卷及教学 PPT 课件。

### 🧮 算法与编程

- **算法设计与分析**
  - **重点**：动态规划、图论算法、回溯法。
  - **内容**：包含作业实现、出题练习、真题卷及完整课件。
- **Java 程序设计**
  - **资料**：平时实验代码、教学课件及针对期末考的专项复习资料。

### 🎮 应用与多媒体

- **游戏基础**
  - **项目实战**：包含 `3500canteen` Unity 实战项目文件夹、lab 实验报告。
  - **文档**：游戏设计文档及配套课件。
- **多媒体技术**
  - **资源**：实验报告 (lab)、期末复习点及教学课件。

### 🗳️ 思政与公共课

- **习概**：2024-2025 年最新思考题汇总、选择题复习 (.pdf)、名师背书版整理。
- **军理**：包含 2016-2023 年历年试卷、复习大纲、名词解释/简答题专项练习。
- **四史**：收录嘉庚精神心得、微党课资料、情景剧策划案等。

## 📝 重点提醒

1. **组原与算法**：这是本学期的“两座大山”，建议尽早开始准备实验，并多做真题巩固算法思路。
2. **网络协议**：深刻理解 TCP/IP 协议栈，实验报告中的分层分析是考试的重点。
3. **数据库实践**：SQL 语句的编写建议在本地环境多测试优化。
