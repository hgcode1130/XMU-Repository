# 大二上 学习资料

本目录下整理了大二上学年的计算机专业核心课程资料，该学期是计算机底层逻辑与数据结构夯实的关键阶段。

## 📁 课程详细列表

### 🏗️ 专业核心课

- **DataStructure (数据结构)**
  - **作业 & 实验**：涵盖链表、树、图等核心结构的实现代码。
  - **规约文档**：包含实验考核要求、教学日历 (2024) 及教学大纲修订版。
  - **复习资料**：数据结构期中真题、期末复习相关重点整理。
- **DigitalLogic (数字逻辑)**
  - **EGO1 开发板**：提供硬件对应的约束文件及开发板使用手册。
  - **实验 & 作业**：包含基础逻辑门设计、时钟电路等实验报告与平时作业。
  - **教学资源**：完整课程课件及期中考试资料。
- **汇编语言**
  - **工具链**：DEBUG 参考资料及 8086 汇编相关模拟工具资料。
  - **源码**：`asm_file` 存放了核心汇编源码段。
  - **复习**：包含实验报告、平时作业、课件及期末复习汇总。
- **离散数学**
  - **资料包**：课件、平时作业答案、课堂笔记。
  - **试卷**：涵盖期中、期末的历年真题，重点在于逻辑演算与图论部分。

## 📝 学习建议

1. **重视实验**：数据结构和汇编语言的学分较高且实验量大，请确保每份实验代码都能独立运行通过。
2. **逻辑训练**：离散数学是算法的基础，建议认真对待平时作业中的思维训练题。
3. **考前突击**：毛概等公共课建议通过整理好的思考题汇总进行高效背诵。
