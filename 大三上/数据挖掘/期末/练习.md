## 第二部分：判断题 (80 题)

1. 标称属性（Nominal）的值之间存在顺序关系。 (**F**，标称属性无序，序数属性才有顺序)
2. 比率属性（Ratio）具有绝对零点，因此可以计算比值。 (**T**)
3. 离群点（Outlier）一定是噪声数据，应该全部删除。 (**F**，离群点也可能包含重要信息，如欺诈检测中的异常交易)
4. 均值比中位数对极端值（离群点）更敏感。 (**T**)
5. 方差和标准差用于度量数据的离散程度。 (**T**)
6. 余弦相似度关注的是向量的长度差异，而不是方向差异。 (**F**，余弦相似度关注方向，不关注长度)
7. Jaccard 系数适合处理非对称的二元属性（如购物篮数据）。 (**T**)
8. 皮尔森相关系数为 0 表示两个变量完全独立。 (**F**，只表示无线性相关)
9. PCA（主成分分析）是一种有监督的降维方法。 (**F**，无监督)
10. 数据规范化（Normalization）可以将不同量纲的属性转换到相同的范围内。 (**T**)
11. 蓄水池采样（Reservoir Sampling）适用于对流数据进行随机采样。 (**T**)
12. 欧几里得距离是闵可夫斯基距离在 r=2 时的特例。 (**T**)
13. 缺失值处理中，对于分类属性，通常用平均值填充。 (**F**，平均值用于数值属性，分类属性通常用众数)
14. 协方差大于 0 表示两个变量正相关。 (**T**)
15. 离散化是将连续属性转换为分类属性的过程。 (**T**)
16. 如果一个项集是频繁的，那么它的所有超集也一定是频繁的。 (**F**，超集不一定频繁，子集一定频繁)
17. Apriori 算法利用先验原理来减少候选项集的数量。 (**T**)
18. 支持度（Support）具有反单调性。 (**T**)
19. 强关联规则必须同时满足最小支持度和最小置信度阈值。 (**T**)
20. 提升度（Lift）等于 1 表示前件和后件相互独立。 (**T**)
21. 关联规则 X -> Y 和 Y -> X 的置信度一定相同。 (**F**，支持度相同但置信度分母不同，通常不同)
22. 关联规则 X -> Y 和 Y -> X 的支持度一定相同。 (**T**)
23. 频繁项集的产生通常比规则生成的计算代价更高。 (**T**)
24. 置信度度量了包含 X 的事务中也包含 Y 的条件概率。 (**T**)
25. Apriori 算法可以一次扫描数据库就找出所有频繁项集。 (**F**，每产生一级频繁项集都需要扫描一次数据库)
26. 分类是一种无监督学习方法。 (**F**，有监督)
27. 决策树算法中，信息增益越大，表示属性的纯度提升越小。 (**F**，信息增益越大，纯度提升越大)
28. 决策树可以处理非线性决策边界。 (**T**)
29. 后剪枝（Post-pruning）通常比预剪枝（Pre-pruning）更能生成精确的树，但计算代价更高。 (**T**)
30. 朴素贝叶斯分类器假设属性之间是相互依赖的。 (**F**，假设属性之间条件独立)
31. 朴素贝叶斯分类器可以处理多分类问题。 (**T**)
32. 拉普拉斯平滑用于解决朴素贝叶斯中的零概率问题。 (**T**)
33. SVM 是基于结构风险最小化原理的。 (**T**)
34. 线性 SVM 通过最大化间隔（Margin）来寻找最优超平面。 (**T**)
35. 支持向量是距离分离超平面最远的那些点。 (**F**，是距离超平面最近的点)
36. 核函数可以将线性不可分数据映射到高维空间使其线性可分。 (**T**)
37. K-近邻（KNN）算法是一种懒惰学习（Lazy Learning）方法。 (**T**)
38. KNN 算法中的 K 值越小，模型越不容易过拟合。 (**F**，K 值越小，模型越复杂，越容易过拟合)
39. 准确率（Accuracy）在处理类别不平衡数据时是一个很好的评估指标。 (**F**，类别不平衡时准确率会误导，应使用 F1、Recall 等)
40. 召回率（Recall）度量了所有正例中有多少被正确预测出来。 (**T**)
