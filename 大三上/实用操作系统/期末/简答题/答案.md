# 操作系统--精髓与设计原理（第八版）

# 第 1 章 复习题答案

**1.1 列出并简要定义计算机的四个组成部分。**

处理器：控制计算机的操作，执行数据处理功能。
内存：也叫主存储器，存储数据和程序。
输入/输出模块：在计算机和外部环境之间移动数据。
系统总线：在处理器、内存和输入输出间提供通信的设施。

**1.2 定义处理器寄存器的两种主要类别。**

用户可见寄存器：优先使用这些寄存器，可以使机器语言或者汇编语言的程序员减少对主存储器的访问次数。对高级语言而言，由优化编译器负责决定把哪些变量应该分配给主存储器，一些高级语言，如 C 语言，允许程序员建议编译器把哪些变量保存在寄存器中。
控制和状态寄存器：用以控制处理器的操作，且主要被具有特权的操作系统例程使用，以控制程序的执行。

**1.3 一般而言，一条机器指令能指定的四种不同操作是什么？**

处理器-寄存器：数据可以从处理器传送到存储器，或者从存储器传送到处理器。
处理器-I/O：通过处理器和 I/O 模块间的数据传送，数据可以输出到外部设备，或者从外部设备输入数据。
数据处理：处理器可以执行很多关于数据的算术操作或者逻辑操作。
控制：某些指令可以改变执行顺序。

**1.4 什么是中断？**

中断是指计算机运行过程中，出现某些意外情况需主机干预时，机器能自动停止正在运行的程序并转入处理新情况的程序，处理完毕后又返回原被暂停的程序继续运行。

**1.5 多个中断的处理方式是什么？**

处理多中断有两种方法。

1. 第一种方法是当正在处理一个中断时，禁止再发生中断。
2. 第二种方法是定义中断优先级，允许高优先级的中断打断低优先级的中断处理器的运行。

**1.6 内存层次各个元素间的特征是什么？**

内存层次结构的特征是：越往上层，单位比特的价格越高、容量越小、速度越快、存取频率越高。

**1.7 什么是高速缓存？**

高速缓存是一种比主存更小、更快的存储器，位于处理器和普通主存之间。它利用局部性原理，存储最近被访问过或者即将被访问的代码和数据副本。

**1.8 列出并简要定义由于使用高速缓存而需要处理的三个设计问题。**

1. 高速缓存大小：高速缓存越小，速度越快但命中率越低；高速缓存越大，性能越好但成本增加。
2. 映射函数：决定了一个主存块存放在高速缓存中的哪个位置。
3. 替换算法：当高速缓存已满且需要调入新块时，决定替换哪个现有的块（如 LRU 算法）。
4. 写策略：决定何时将高速缓存中被修改的数据写回主存。

**1.9 区分指令隔离和数据隔离。**

指令隔离（I-Cache）：专门用于存储指令的高速缓存。
数据隔离（D-Cache）：专门用于存储数据的高速缓存。
使用独立的高速缓存可以简化处理器流水线的设计并减少物理冲突。

**1.10 什么是直接内存存取（DMA）？**

直接内存存取（DMA）是一种 I/O 技术，允许 I/O 模块直接与内存之间进行数据交换，而无需处理器的持续干预，从而大大减少了处理器的开销。

# 第 2 章 复习题答案

**2.1 操作系统控制的三种资源是什么？**

1. 处理器资源。
2. 内存资源。
3. I/O 设备资源（以及数据/文件资源）。

**2.2 什么是操作系统的就绪态？**

在这个状态下，进程已经准备好运行，只要处理器有空闲就可以立即执行。

**2.3 描述单道批处理操作系统、多道批处理操作系统和分时操作系统的区别。**

单道批处理：一次只运行一个程序，处理器大部分时间处于等待 I/O 的空闲状态。
多道批处理：内存中同时存放多个程序，当一个程序等待 I/O 时，处理器可以切换到另一个程序运行，提高了处理器利用率。
分时系统：多个用户通过终端同时使用计算机，操作系统以极短的时间片轮流为每个用户服务，使用户感觉自己独占计算机。

**2.4 什么是分时系统？**

分时系统（Time-sharing system）是一种多用户操作系统，它允许多位用户通过各自的终端同时与系统交互，每个用户分得一个小的时间片。

**2.5 操作系统的五个主要成就。**

1. 进程。
2. 内存管理。
3. 信息安全和保护。
4. 调度和资源管理。
5. 系统结构。

**2.6 什么是进程？**

进程通常被定义为一个正在执行的程序实例，它不仅包含程序代码，还包含当前活动（通过程序计数器的值和处理器寄存器的内容表示）。

**2.7 为实现进程管理，操作系统需要哪些功能？**

操作系统需要能够创建和销毁进程、切换进程（上下文切换）、进程通信、进程同步以及处理进程死锁等。

**2.8 描述虚存管理。**

虚存管理允许程序在执行时不必全部装入物理内存。它通过将进程的一部分放在内存中，另一部分放在磁盘上，在需要时按需调入，从而使程序可以使用比实际物理内存大得多的逻辑空间。

# 第 3 章 复习题答案

**3.1 什么是指令轨迹？**

指令轨迹（Instruction Trace）是指一个进程执行过程中所经过的指令序列。

**3.2 什什么是进程控制块（PCB）？**

进程控制块是操作系统用来管理进程的数据结构，包含进程标识符、进程状态、程序计数器、内存限制、优先级、I/O 状态信息等关键信息。

**3.3 设置进程状态的两个基本原因是什么？**

1. 在多道程序环境中，处理器需要在多个就绪进程之间切换以提高效率。
2. 某些进程可能因为等待 I/O 或其他事件而暂时无法运行（阻塞），通过区分状态可以避免浪费处理器时间。

**3.4 除了在状态转换图中看到的各种状态外，进程还包含哪些主要成分？**

进程由程序代码、数据集以及用于描述其执行状态的进程控制块（PCB）组成。

**3.5 进程切换和模式切换有什么区别？**

模式切换（Mode Switch）：在同一个进程中，由于系统调用或中断，处理器从用户模式切换到特权模式。不改变进程上下文。
进程切换（Process Switch）：处理器从一个进程切换到另一个不同的进程，涉及完整的上下文保存和恢复，开销更大。

**3.6 一个典型的进程控制块（PCB）中包含哪些信息？**

1. 进程标识符。
2. 处理器状态信息（寄存器值等）。
3. 进程控制信息（状态、优先级、调度参数、资源清单等）。

**3.7 模式切换和进程切换的关系是什么？**

进程切换必定包含模式切换，但模式切换不一定会导致进程切换。模式切换通常是执行进程切换的前置步骤。

**3.8 操作系统的核心功能通常哪些？**

1. 进程管理（创建、调度、切换、同步）。
2. 内存管理（分配、分页、分段）。
3. I/O 管理（缓冲、通道管理）。
4. 文件系统管理。
5. 系统保护和恢复。

# 第 5 章 复习题答案

**5.1 如果一个系统中有两个或多个进程并行执行，列出可能出现的三种困难。**

1. 共享资源的竞争：多个进程试图同时访问同一资源（如磁盘）。
2. 操作系统资源分配不当：可能导致死锁。
3. 调试困难：由于进程执行的不可预测性和交互性，很难准确复现某种执行顺序。

**5.2 什么是竞争条件（Race Condition）？**

当多个进程或线程并发访问并操纵相同的数据，且执行结果取决于它们访问发生的特定顺序时，称之为竞争条件。

**5.3 什么是死锁？什么是饥饿？**

死锁（Deadlock）：两个或多个进程因互相等待对方持有的资源而永远无法继续执行的状态。
饥饿（Starvation）：一个就绪进程由于调度策略的偏向或资源分配问题，在可以无限期运行的系统中永远无法获得执行机会的情况。

**5.4 定义排他控制、临界区、忙等这三个术语。**

排他控制（Mutual Exclusion）：当一个进程在临界区内访问共享资源时，其他任何进程都不能进入其临界区。
临界区（Critical Section）：进程中涉及访问和修改共享资源的代码段。
忙等（Busy Waiting）：进程反复执行循环检查某个条件（如锁是否释放），而没有进入阻塞状态让出 CPU。

**5.5 互斥的要求是什么？**

1. 必须强制实施互斥。
2. 即使在非临界区的进程崩溃，也不应影响其他进程进入临界区。
3. 进入临界区的等待请求应在有限时间内得到满足（无死锁、无饥饿）。
4. 当没有进程处于临界区时，请求进入的进程应能立即进入。
5. 对处理器的速度和数量不做假设。
6. 一个进程驻留在临界区的时间必须是有限的。

**5.6 简述信号量的操作原语 P(s) 和 V(s)。**

P(s) 操作：如果信号量 s 大于 0，则 s 减 1 并继续；如果 s 等于 0，则该进程进入阻塞队列。
V(s) 操作：如果阻塞队列中没有进程，则 s 加 1；如果阻塞队列中有进程，则唤醒其中一个进程。

**5.7 什么是计数信号量？什么事二值信号量？**

计数信号量（Counting Semaphore）：其值可以是任何非负整数，常用于管理具有多个实例的资源。
二值信号量（Binary Semaphore）：其值只能是 0 或 1，主要用于实现互斥锁。

**5.8 为什么 V 操作是原语且必须是不可取消的？**

如果 V 操作不是原语，在更新信号量值和唤醒进程之间可能被中断，导致原本应该被唤醒的进程继续睡眠，从而引起系统死锁。

**5.9 什么是监视器（Monitor）？**

监视器是一种高级同步原语，它将相关的变量及其管理操作封装在一个特殊的程序块中，确保同一时间只有一个进程能执行监视器内的操作，从而自动实现互斥。

**5.10 什么是消息传递？消息传递的两个原语是什么？**

消息传递是一种进程间通信（IPC）机制。其主要原语是 `send(destination, message)` 和 `receive(source, message)`。

**5.11 阻塞消息传递和无阻塞消息传递的区别。**

阻塞发送：发送者等待直到消息被接收者接收。
无阻塞发送：发送者发送消息后立即继续执行。
阻塞接收：接收者等待直到有消息到达。
无阻塞接收：如果没消息，接收者立即返回或执行其他操作。

**5.12 解决生产者-消费者问题的几种方法。**

1. 使用信号量。
2. 使用监视器。
3. 使用消息传递。

# 第 6 章 复习题答案

**6.1 什么是死锁？给出死锁的定义。**

死锁是指在一组进程中，每个进程都持有一部分资源且都在无限等待另一进程持有的资源，导致整组进程都无法继续执行。

**6.2 死锁产生的四个必要条件。**

1. 互斥条件。
2. 占有且等待条件。
3. 不可剥夺条件。
4. 循环等待条件。

**6.3 什么是死锁预防？**

通过破坏死锁产生的四个必要条件中的一个或多个（除了互斥通常无法破坏外），使系统永远不会产生死锁的一组静态限制规则。

**6.4 什么是死锁避免？**

这种方法允许进程请求资源，但要在分配前动态检查该分配是否会导致系统进入不安全状态。如果分配后系统可能进入不安全状态，则拒绝该请求（例如银行家算法）。

**6.5 银行家算法的基本原理。**

银行家算法根据每个进程对资源的最大需求量、当前已分配量以及系统剩余可用量进行模拟分配，仅当分配后仍能找到一个满足所有进程完成的安全序列时，才进行实际分配。

**6.6 什么是死锁检测？**

系统允许死锁发生，但会定期运行一个算法来检测当前是否存在死锁。如果检测到死锁，将采取补救措施（如撤销进程、剥夺资源）。

**6.7 为什么要处理死锁？**

如果不对死锁进行处理，系统的资源利用率会下降，甚至导致整个系统挂起，严重影响系统吞吐量和可靠性。

**6.8 死锁恢复的方法有哪些？**

1. 撤销一个或多个死锁进程（通常撤销代价最小的）。
2. 将死锁进程回退到之前的安全检查点重新运行。
3. 剥夺死锁进程的一部分资源给其他进程使用。

**6.9 资源分配图是什么？**

资源分配图是有向图，用于描述系统中进程对资源的占有和请求情况。圆圈表示进程，矩形表示资源类，箭头方向表示分配或请求关系。

**6.10 安全状态和死锁状态的区别。**

安全状态指存在一个进程序列，按此序列分配资源能使所有进程顺利完成。
死锁状态是已经发生了循环等待且无法打破的状态。
注意：不安全状态不一定是死锁状态。

**6.11 死锁避免和死锁预防的区别。**

死锁预防通过静态规则限制资源的分配。
死锁避免根据当前的资源状态进行动态判断和预测。

**6.12 为什么要区分互斥资源和非互斥资源？**

因为非互斥资源（如只读文件）允许多个进程同时访问，天然不会产生竞争导致的死锁。互斥资源则必须进行排他性控制。

**6.13 列出解决死锁的三种通用方法。**

1. 死锁预防。
2. 死锁避免。
3. 死锁检测与恢复。

# 第 7 章 复习题答案

**7.1 设置内存管理的四个基本目标。**

1. 保护和授权。
2. 共享。
3. 逻辑组织。
4. 物理组织。

**7.2 什么是内碎片？什么是外碎片？**

内碎片：由于分配的存储块大于进程实际需要的，导致分配块内部未被使用的空间。
外碎片：由于动态分配导致内存中出现许多零散的、过小的空闲块，虽然总和足够大，但无法满足大进程的需求。

**7.3 区分分页和分段。**

分页（Paging）：将内存和进程都划分为固定大小的小块（页和页框）。主要解决碎片问题，对用户透明。
分段（Segmentation）：按照程序的逻辑结构将进程划分为变长段。利于共享、保护和模块化。

**7.4 页和页框有什么关系？**

页（Page）是进程逻辑上的划分。
页框（Page Frame）是物理内存上的划分。
一页的大小通常等于一个页框的大小。

**7.5 什么是逻辑地址？什么是物理地址？**

逻辑地址：程序中使用的相对地址，相对于进程的起始。
物理地址：内存硬件中的实际存储位置。

**7.6 地址转换。**

地址转换（Address Translation）是指将指令中的逻辑地址映射为物理地址的过程。在分页系统中，这通过页表完成。

**7.7 说出内存分配的三种放置算法。**

1. 最佳适配（Best-fit）：选择大小最接近要求的空闲块。
2. 首次适配（First-fit）：选择第一个足够大的空闲块。
3. 下次适配（Next-fit）：从上次分配位置开始搜索。

**7.8 什么是重定位？**

由于程序可能会在内存中被移动（由于交换或压缩），重定位是指修改进程的代码和数据中的地址引用，使其在新位置也能正确运行。

**7.9 写出分页和分段的区别。**

1. 分页是管理物理内存的单位，分段是管理程序的逻辑单位。
2. 页的大小固定，段的大小不固定。
3. 分页对程序员透明，分段程序员可见（如段号和段内偏移）。

# 第 8 章 复习题答案

**8.1 什么是虚存？**

虚存是指操作系统利用磁盘空间作为内存的扩展，使得进程可以使用远大于实际物理内存的逻辑地址空间。

**8.2 什么是抖动（Thrashing）？**

当系统频繁地在内存和磁盘之间进行页交换，导致处理器的大部分时间都用于 I/O 而非执行指令时，这种极端性能下降的现象称为抖动。

**8.3 什么是局部性原理？**

时间局部性：被访问过的数据近期很有可能再次被访问。
空间局部性：被访问过的数据其相邻位置的数据近期也很有可能被访问。

**8.4 虚存管理的三个关键决策。**

1. 读取策略（何时调入页）。
2. 放置策略（调入何处）。
3. 替换策略（替换哪一页）。

**8.5 简述先进先出（FIFO）页面替换算法和最近最少使用（LRU）页面替换算法。**

FIFO：总是替换最早进入内存的页面。实现简单但可能导致 Belady 异常。
LRU：总是替换最长时间未被访问过的页面。性能较好但硬件开销大。

**8.6 什么是驻留集管理？**

驻留集指分配给一个进程的物理页框数量。驻留集管理可以分为固定分配和可变分配。

**8.7 读取策略的两种主要方法。**

1. 请求分页：仅在发生缺页中断时才调入所需页。
2. 预分页：在程序执行前或预测其可能需要时，提前调入多个连续页。

**8.8 什么是置换范围？**

置换范围可以分为局部置换（仅在出错进程的驻留集中选择）和全局置换（在所有进程的空闲或已用块中选择）。

**8.9 简述工作集模型。**

工作集模型是通过跟踪进程在最近一段时间内访问过的页面集合，来动态调整进程驻留集的大小，从而防止抖动。

**8.10 虚存的分页表通常要包含哪些信息？**

页号、对应的页框号、状态位（是否在内存中）、修改位（是否被写过）、保护位等。

**8.11 请求分页有哪些优点？**

1. 提高了多道程序度。
2. 允许运行比内存大的程序。
3. 减少了进程启动时的延时。

**8.12 虚拟地址转化为物理地址。**

在请求分页系统中，通过查询页表，将虚拟页号转换为页框号，再结合页内偏移量组合成物理地址。若页不在内存中，则产生缺页中断。

# 第 9 章 复习题答案

**9.1 处理器调度的四种类型。**

1. 长程调度：决定哪些进程可以进入系统。
2. 中程调度：决定哪些进程在内存中，哪些在磁盘中。
3. 短程调度：决定哪个就绪进程获得处理器。
4. I/O 调度：决定哪个待处理的 I/O 请求被处理。

**9.2 短程调度的主要目标。**

在满足系统目标（如吞吐量、负载平衡）的同时，尽量提高处理器利用率并降低平均周转时间和响应时间。

**9.3 抢占式调度和非抢占式调度的区别。**

非抢占式：一旦进程获得处理器，就一直运行直到它主动释放（如完成或等待 I/O）。
抢占式：操作系统可以随时中断正在运行的进程，将处理器分配给另一个优先级更高的或时间片到期的进程。

**9.4 定义周转时间、响应时间、吞吐量。**

周转时间：进程从提交到完成的总时间。
响应时间：从提交请求到产生第一次响应的时间。
吞吐量：单位时间内系统完成的进程数量。

**9.5 请解释选择调度算法的五个标准。**

1. CPU 利用率。
2. 吞吐量。
3. 周转时间。
4. 等待时间。
5. 响应时间。

**9.6 简述先来先服务（FCFS）和最短作业优先（SJF）调度算法。**

FCFS：按请求顺序分配处理器，简单但不公平（长作业会阻塞短作业）。
SJF：优先调度执行时间最短的作业，能获得最短的平均周转时间，但长作业可能饥饿。

**9.7 什么是轮转调度（Round Robin）？**

系统为每个进程分配一个固定大小的时间片，轮流执行。时间片用完后进程回到就绪队列末尾。

**9.8 什么是多级反馈队列调度？**

设置多个不同优先级的队列，新进程进入高优先级队列，随执行时间增加逐渐降入低优先级队列，并针对不同队列采取不同的时间片和调度方式。

**9.9 定义最高响应比优先（HRRN）调度算法。**

响应比 = (等待时间 + 要求服务时间) / 要求服务时间。优先选择响应比最高的进程，兼顾了短作业和长时间等待的长作业。

**9.10 什么是调度器？什么是分派器？**

调度器（Scheduler）：负责决定哪个进程该运行。
分派器（Dispatcher）：负责实际的上下文切换和跳转到目标代码执行。

**9.11 请列出实现多处理器调度的方法。**

1. 主从式：一个处理器负责所有调度和资源管理。
2. 同步式：多个处理器地位平等，互为备份或竞争式获取任务。

**9.12 实时调度的特点是什么？**

实时调度强调结果的及时性和可确定性，必须在严格的时间限制（截止期限）内完成任务。

# 第 11 章 复习题答案

**11.1 列出并简要定义执行 I/O 的三种技术。**

程序 I/O：处理器持续检查 I/O 模块的状态（忙等）。
中断驱动 I/O：I/O 模块准备好后向处理器发送中断。
直接内存存取（DMA）：I/O 模块直接在内存和外部设备间移动数据。

**11.2 I/O 操作系统的目标是什么？**

效率和通用性。

**11.3 什么是 I/O 缓冲？**

在数据传输过程中，将数据暂时存放在内存的特定区域，以缓解 I/O 设备与 CPU 速度不匹配、平衡数据传输单位大小不一致等问题。

**11.4 什么是块 I/O 设备和流 I/O 设备？**

块设备：以块为单位存储和检索数据（如磁盘）。
流设备：以字节流形式发送或接收数据（如键盘、打印机）。

**11.5 列出并简单定义四个磁盘调度算法。**

1. FCFS：按请求到达顺序。
2. SSTF（最短寻道时间优先）：选择距离当前磁头位置最近的磁道。
3. SCAN（电梯算法）：磁头沿一方向移动扫描，到头后反向。
4. C-SCAN（循环扫描）：只在一个方向移动扫描，到头后快速返回起点重新开始。

**11.6 什么是 RAID？**

冗余磁盘阵列（Redundant Array of Independent Disks），通过将多个物理磁盘组合为一个逻辑单元，利用并行访问和纠错码来提高性能和可靠性。

**11.7 RAID0, RAID1, RAID5 的区别。**

RAID0：数据条带化，无冗余，性能最高，可靠性最低。
RAID1：镜像冗余，数据完全复制，成本高。
RAID5：带奇偶校验的条带化，兼顾容量、性能和故障恢复能力。

**11.8 什么是磁盘扇区和磁盘柱面？**

扇区：磁盘上最小的物理寻道单位。
柱面：所有盘面上具有相同半径的磁道集合。

**11.9 请解释磁盘读取时间由哪几部分组成。**

1. 寻道时间：移动磁头到正确磁道的时间。
2. 旋转延迟：等待扇区转到磁头下方的时间。
3. 传输时间：实际数据移动的时间。

**11.10 什么是缓冲区高速缓存？**

专门用于存放磁盘块副本的内存区域，通过减少物理磁盘访问次数来提高 I/O 效率。

**11.11 什么是通道（Channel）？**

通道是一种具有指令系统的特殊处理器，专门负责控制复杂的 I/O 操作，使主处理器能从繁重的 I/O 管理中解脱出来。

**11.12 为什么要区分磁盘驱动程序的策略和磁盘硬件的控制？**

驱动程序策略（如调度算法）由操作系统控制，可根据负载调整；而硬件控制（如磁头移动速度、纠错）由硬件厂商优化，两者解耦有助于系统的通用性和灵活性。

# 第 12 章 复习题答案

**12.1 什么是文件管理系统？**

文件管理系统是操作系统中负责管理磁盘上的数据组织、存储、保护和访问权限的软件集合。

**12.2 文件和目录的关系。**

文件是数据的集合。目录是一个特殊的文件，包含其他文件或子目录的索引和位置信息。

**12.3 文件属性通常包括什么？**

文件名、文件类型、所有者、权限、大小、创建时间、最后修改时间等。

**12.4 什么是绝对路径名？什么是相对路径名？**

绝对路径：从根目录（/）开始的完整描述。
相对路径：相对于当前工作目录的描述。

**12.5 定义文件组织。**

文件组织是指数据在文件内部的逻辑排列方式，如顺序、索引或哈希组织。

**12.6 列出并简单定义五个文件组织。**

1. 堆文件：数据按到达顺序存放，无结构。
2. 顺序文件：各记录按关键字顺序排列，固定长度。
3. 索引顺序文件：在顺序文件基础上增加一级索引以支持快速访问。
4. 索引文件：数据完全通过索引访问。
5. 哈希文件：通过哈希函数计算记录的存储地址，支持极速查找。

**12.7 典型目录包含哪些操作？**

查找、创建文件、删除文件、显示目录以及修改目录。

**12.8 路径名和工作目录有什么关系？**

路径名是从根开始或相对于当前位置的完整序列。工作目录是用户当前所处的默认路径，允许用户使用较短的相对路径名。

**12.9 可以授予或拒绝的某个特定用户对某个特定文件的访问权限通常有哪些？**

执行、读、写/更新、追加、删除以及权限管理权。

**12.10 列出并简单定义三种组块方法。**

1. 固定组块：每个块包含固定数量的记录，可能存在内部碎片。
2. 变长跨越式组块：记录长度可变，且一个记录可以分在两个连续块中，通过指针连接。
3. 变长非跨越式组块：记录长度可变，但必须完整存在于一个块中。

**12.11 列出并简单定义三种文件分配方法。**

1. 连续分配：分配一组连续的磁盘块，读写块快但会有外部碎片。
2. 链式分配：每个块包含指向下一个块的指针，灵活性高但不支持随机访问。
3. 索引分配：为每个文件分配一个索引块，存储所有数据块的地址，支持高效的随机访问。
