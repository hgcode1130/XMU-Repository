# 第 3 章：进程描述和控制


### 第一列

- **阻塞态 (Blocked State)**：进程正在**等待某一事件的完成**（如一次 I/O 操作），在事件完成前不能执行。
- **子进程 (Child Process)**：由现有进程（父进程）通过**进程派生**（process spawning）产生的进程。
- **退出态 (Exit State)**：进程从可执行进程组中释放，通常是因为程序**运行完成或被取消**，其相关信息由操作系统暂时保留以供辅助程序提取。
- **中断 (Interrupt)**：允许其他模块（如 I/O、存储器）**打断处理器正常处理过程**的机制，用于提高处理器的效率。
- **内核态 (Kernel Mode)**：处理器的一种高权限执行模式，允许执行**特权指令**并访问受保护的内存区域，通常为操作系统内核运行的模式。
- **模式切换 (Mode Switch)**：处理器在发生中断或系统调用时，从用户模式切换到内核模式，或者从内核模式恢复到用户模式的过程，此时**不需要进行进程切换**。
- **新建态 (New State)**：刚刚创建且操作系统**尚未将其加入可执行进程组**的进程状态，通常其进程控制块（PCB）已创建但程序未加载入内存。

### 第二列

- **父进程 (Parent Process)**：显式请求创建一个新进程的**原有进程**。
- **抢占 (Preemption)**：操作系统收回一个正在运行进程所占用的处理器资源，并将其状态转为就绪态的行为。
- **特权态 (Privileged Mode)**：又称系统模式或内核模式，在此模式下软件可以**完全控制处理器**及其所有指令和资源。
- **进程 (Process)**：一个**正在执行的程序实例**，由程序代码、数据集和相关的执行上下文（进程控制块）组成。
- **进程控制块 (Process Control Block, PCB)**：操作系统用来**管理和控制进程**所需的数据结构，包含标识符、状态、优先级、程序计数器等信息。
- **进程映像 (Process Image)**：进程物理上的集合，包括**程序、数据、栈和进程控制块**。

### 第三列

- **进程切换 (Process Switch)**：操作系统停止运行当前进程，保存其上下文，并**调度另一个就绪进程进入运行态**的完整过程。
- **程序状态字 (Program Status Word, PSW)**：处理器内部包含状态信息的寄存器，通常包含条件码及执行模式（如用户/内核模式）等位信息。
- **就绪态 (Ready State)**：进程已经做好了执行准备，**只要有机会（被分配到处理器）就开始执行**的状态。
- **轮转 (Round Robin)**：一种调度策略，基于时间片抢占，依次给就绪队列中的每个进程分配一段执行时间。
- **运行态 (Running State)**：进程当前**正在被处理器执行**的状态。
- **挂起态 (Suspend State)**：当主存空间不足时，操作系统将某些进程转移到辅存（磁盘）中，该进程**临时退出主存**进入挂起状态。

### 第四列

- **交换 (Swap)**：为了释放内存空间，操作系统将内存中某个进程的一部分或全部移动到磁盘（辅存）中，或将其从磁盘移回内存的操作。
- **系统态 (System Mode)**：处理器的特权执行模式，即内核模式。
- **任务 (Task)**：在某些操作系统中与“进程”同义，指可分派的或拥有资源所有权的单位。
- **跟踪 (Trace)**：描述单个进程行为的**指令执行序列**。
- **陷阱 (Trap)**：与当前执行指令相关的**内部事件（如错误或异常条件）**引起的中断，用于操作系统捕获并处理异常。
- **用户态 (User Mode)**：处理器的**低权限执行模式**，用户程序在此模式下运行，无法执行特权指令或直接访问受保护的内存。
