# 第 2 章：操作系统概述

### 第一列

- **批处理**：用户不直接与计算机交互，而是将作业提交给管理员，由管理员按顺序组织成**批**并放在输入设备上供监控程序处理的操作方式。
- **批处理系统**：利用一种称为**监控程序**的软件，通过自动加载下一个作业来提高处理器利用率的操作系统形式。
- **执行上下文**：又称**进程状态**，是操作系统管理和控制进程所需的内部数据，包括寄存器内容、进程优先级以及该进程是否在等待 I/O。
- **中断**：一种允许其他模块（如 I/O、存储器）中断处理器正常处理过程的机制，旨在提高处理器的效率。
- **作业**：用户提交给批处理系统的一个**任务或程序单元**。
- **作业控制语言 (JCL)**：一种特殊类型的程序设计语言，用于为批处理系统的监控程序提供**作业处理指令**。
- **内核**：操作系统中最常使用的功能部分，常驻于主存中，包含进程管理、内存管理等核心功能。
- **内核模式**：处理器的一种高权限执行模式，允许执行**特权指令**并访问受保护的内存区域。
- **平均失效时间 (MTTF)**：系统在发生故障前预期能够**正确运行**的平均时间段。
- **平均修复时间 (MTTR)**：修复或替换故障部分所花费的**平均时间**。
- **内存管理**：操作系统的一项职责，负责在存储分级体系间**动态分配空间**并移动信息，以确保多个进程能有效利用主存。
- **微内核**：一种只给内核分配最基本功能（如地址空间、进程间通信和基本调度）的操作系统体系结构，其他服务则由用户模式下的进程提供。
- **管程**：一种程序设计语言结构，封装了变量和访问过程，通过强制**互斥**访问来确保并发进程安全地共享数据。

### 第二列

- **单体内核**：一种将大多数操作系统功能（如调度、文件系统、网络等）都实现在一个**大内核**中并共享同一地址空间的体系结构。
- **多道批处理系统**：在主存中同时保留多个作业，当当前作业等待 I/O 时，处理器可以切换到另一个作业执行的批处理系统。
- **多道程序设计**：一种使处理器同时处理多个程序的技术，旨在通过交替执行来**提高处理器利用率**。
- **多任务**：在现代操作系统中通常与“多道程序设计”同义，指系统能同时管理并执行多个任务。
- **多线程**：在单个进程内支持**多个并发执行路径**的技术，线程是可分派的工作单元。
- **核心 (Nucleus)**：常与“内核”通用，指操作系统中最核心、常驻内存的控制部分。
- **操作系统**：控制应用程序执行的程序，充当用户/应用程序与计算机硬件之间的**接口**，负责资源管理。
- **物理地址**：数据在内存中的**实际存储位置**地址。
- **特权指令**：只能由内核执行的机器指令，如 I/O 指令和改变控制寄存器的指令。
- **进程**：一个**正在执行的程序实例**，是操作系统进行资源分配和保护的基本单位。
- **进程状态**：表征进程在任意给定时刻的属性集合（如运行态、就绪态、阻塞态等）。
- **实地址**：即物理地址，对应于主存储器中存储单元的固定位置。
- **常驻监控程序**：批处理系统中**总是处于内存中**并负责控制作业执行顺序的软件部分。

### 第三列

- **时间片轮转**：一种调度策略，依次给就绪队列中的每个进程分配一段执行时间，时间到期后进程被抢占并返回队列。
- **调度**：操作系统决定哪一个可用进程将被处理器执行的过程，分为长程、中程和短程调度。
- **串行处理**：早期计算机的操作模式，用户必须按顺序排队并手动加载程序，**没有操作系统**。
- **对称多处理 (SMP)**：一种体系结构，由一个统一的操作系统控制多个地位平等的处理器，这些处理器共享内存和 I/O 设备。
- **线程**：进程中的一个**实体**，是被系统独立调度和分派的基本单位，拥有自己的上下文和栈。
- **分时系统**：一种多道程序设计形式，允许多个用户通过终端同时访问系统，处理器以时间片为单位在多个用户间**交替执行**。
- **时间片**：在轮转调度中，分配给每个进程的一次性**执行时长**。
- **单道程序设计**：在任一时刻主存中仅允许运行一个程序的环境，处理器必须等待 I/O 完成才能继续计算。
- **用户模式**：用户程序运行的非特权模式，不能执行特权指令，访问内存区域受限。
- **虚拟地址**：在虚拟内存中分配的逻辑地址，由页号和偏移量组成，需经过映射转换为物理地址。
- **虚拟机**：通过软件模拟物理计算机特性的结构，允许在一台物理主机上同时运行多个隔离的操作系统。
- **虚存**：一种存储机制，允许程序使用比实际物理内存大得多的逻辑空间，通过分页或分段技术实现按需调入内存。

---

**比喻辅助理解：**
**进程与线程**的关系就像一家**工厂和流水线**：**进程**是拥有厂房、原材料和电力（内存、资源）的工厂；**线程**则是工厂里的流水线。一个工厂可以只有一条流水线（单线程），也可以有多条流水线同时开工（多线程），它们共享工厂里的所有原材料，但每条流水线都有自己当前的进度记录（程序计数器）和操作台（栈）。
