# 第 11 章：I/O 管理和磁盘调度

### 第一列：I/O 与设备基础

- **块 (Block)**：二级存储（如磁盘）进行 I/O 操作的**基本单位**，通常由多个逻辑记录组成。在 RAID 0 中，数据以条带（包含一个或多个块）的形式分布在磁盘阵列中。
- **面向块的设备 (Block-oriented device)**：将信息保存在固定大小块中的设备，数据传送以**整块**为单位，典型例子包括磁盘和 USB 智能卡。
- **循环缓冲区 (Circular buffer)**：由两个以上缓冲区组成的组织方案，这组缓冲区本身被当作一个环形队列，用于平滑 I/O 设备与进程之间的数据流。
- **CD-R**：**可记录光盘**，用户可以且仅能往光盘上写一次数据，提供了一种永久记录大量用户数据的方式。
- **CD-ROM**：**只读存储压缩光盘**，利用激光技术存储计算机数据，其内容在制造后不可更改，适用于大规模分发信息。
- **中断驱动 I/O (Interrupt-driven I/O)**：处理器向 I/O 模块发出命令后继续执行其他指令，当 I/O 模块准备好交换数据时，通过**中断信号**通知处理器，避免了处理器的不必要等待。
- **输入/输出 (I/O)**：计算机系统与外部环境（如人、机器或其他通信设备）之间**移动数据**的设施和过程。
- **I/O 缓冲区 (I/O Buffer)**：位于内存中，用于**临时保存** I/O 传送数据的区域，目的是平滑处理器与外设之间的速度差异并允许进程在 I/O 期间被换出。
- **I/O 通道 (I/O channel)**：具有专门为 I/O 设计的**指令集**的独立处理器，能够在没有 CPU 干预的情况下执行一序列 I/O 活动。
- **I/O 处理器 (I/O processor)**：功能更强大的 I/O 通道，拥有**局部存储器**，本质上是一台负责控制终端等任务的专用计算机。
- **逻辑 I/O (Logical I/O)**：I/O 逻辑结构中的一层，将设备视为逻辑资源处理，允许用户进程通过设备标识符和简单命令（如读、写）与设备交互，而不必关心底层细节。
- **磁盘 (Magnetic Disk)**：一种表面涂有磁性物质的金属或塑料圆盘，通过磁头进行数据的读写，是计算机主要的二级存储设备。

### 第二列：磁盘结构与性能参数

- **磁盘组 (Disk pack)**：由多个垂直堆叠在一起的磁盘片组成的集合，共享一个转轴。
- **固定头磁盘 (Fixed-head disk)**：磁盘系统的磁头是固定的，**每个磁道**都拥有一个专门的读/写磁头，从而消除了寻道时间。
- **软盘 (Floppy disk)**：一种轻巧、可更换且成本较低的小容量磁存储介质，磁头直接接触盘面进行读写。
- **间隙 (Gap)**：磁道或扇区之间未使用的空间，用于**防止干扰**并补偿磁头的对准误差。
- **硬盘 (Hard disk)**：刚性的、通常不可移动的磁存储设备，用于长期存储程序和数据文件。
- **可换式磁盘 (Removable disk)**：可以从驱动器中取出并由另一个磁盘替换的存储介质，其优点是存储容量理论上无限。
- **旋转延迟 (Rotational delay)**：在选定磁道后，等待目标扇区**旋转到磁头下**所花费的时间。
- **扇区 (Sector)**：磁道被划分成的固定长度的小段，是磁盘上**最小的物理寻址单元**。
- **寻道时间 (Seek time)**：将磁头臂移动到指定磁道上所需要的时间。
- **面向流的设备 (Stream-oriented device)**：以**字节流**方式输入输出数据的设备，不具备块结构，如键盘、鼠标和打印机。
- **磁道 (Track)**：磁盘表面上的一组同心圆，数据就存储在这些磁道上。
- **传送时间 (Transfer time)**：数据从磁盘读出或写入磁盘所需的实际时间，取决于磁盘旋转速度和要传输的字节数。

### 第三列：高级存储与存取技术

- **固定磁盘 (Nonremovable disk)**：永久安装在磁盘驱动器中，不可移动的硬盘。
- **可编程 I/O (Programmed I/O)**：一种简单的 I/O 方式，处理器代表进程发出命令后，必须不断轮询（**忙等待**）I/O 模块的状态直至操作完成，严重降低了处理器效率。
- **读/写头 (Read/write head)**：磁控装置，能在磁盘表面上方悬浮（或接触）以检测或改变盘面的磁化状态，从而实现读写。
- **独立磁盘冗余阵列 (RAID)**：将多个物理磁盘驱动器组合成一个**逻辑驱动器**的标准方案，通过条带化和冗余数据（如奇偶校验）来提高 I/O 性能和可靠性。
- **CD-RW**：**可擦写光盘**，可以像磁盘一样反复多次写码和覆盖数据，能充当真正的辅助存储器。
- **柱面 (Cylinder)**：磁盘组中，所有盘面上**距离转轴距离相等**的磁道集合。
- **设备 I/O (Device I/O)**：将逻辑 I/O 层的请求转化为具体的 I/O 指令序列、通道命令或控制器指令的过程。
- **数字化视频光盘 (DVD)**：比 CD 容量大得多的光盘技术，由于其激光波长更短且采用了多层/双面存储技术，容量可达 CD 的数倍。
- **直接存储器访问 (DMA)**：由专门的硬件模块接管数据传送任务，允许数据在 I/O 模块和内存之间**直接交换**，而无需处理器干预，仅在传送开始和结束时中断处理器。
- **磁盘存取时间 (Access time)**：磁头达到读写位置的总时间，等于**寻道时间加上旋转延迟**。
- **磁盘高速缓存 (Disk cache)**：内存中划出的一块区域，用于保留磁盘部分扇区的副本，利用**局部性原理**减少物理磁盘访问次数，提髙系统响应速度。
- **活动头磁盘 (Movable-head disk)**：磁头安装在可移动的磁头臂上，磁头可以跨越磁道移动以定位到目标地址。
