## 📝 学习 tips

1. **真题为王**：数学类课程（线代、概统）建议至少刷完近三年的真题，掌握出题风格。
2. **动手实践**：C/C++ 的期中资料中含有很多基础代码题，建议手动实现一遍而非只看答案。
3. **分阶段复习**：期中后的资料通常包含更多综合性大题，建议分章节攻克。
